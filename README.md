# Vibecoding 1

## Doodle Garden

A single-file symmetry drawing app. Draw on the canvas and your strokes are repeated around the center to make mandala-style patterns.

**Run it:** open `doodle-garden/index.html` in any modern browser. No build step or dependencies.

**Controls**
- **Symmetry** – number of rotational copies (2–16)
- **Brush** – stroke width
- **Palette** – Rainbow, Sunset, Ocean, Forest or Mono
- **Mirror** – also reflect each copy
- **Undo** (or `Ctrl/Cmd+Z`), **Clear**, **Save PNG**
